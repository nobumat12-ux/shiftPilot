# ShiftPilot v0.5.5 — 試作版

## 更新内容
- 週契約の一括入力：開始・終了・休憩（分）を変更し、チェックした曜日に適用。
- 基準時刻人数：1つずつ時間ピッカーで追加・削除（最大5件）。
- 月間シフト：印刷専用ウィンドウでA4横向き・日付縦・全スタッフ横の1枚印刷に対応。ブラウザやプリンタによって縮小率の調整が必要な場合があります。
- 既存のPWA対応を維持。service-worker.jsのキャッシュ版を更新。

## GitHubへの配置
`index.html` と `service-worker.js` を必ず更新してください。`manifest.webmanifest` と `icons/` は従来版をそのまま利用できます。

## 注意
現在は認証や端末間同期のない、ブラウザ内の localStorage を用いる試作版です。本物の社員番号、氏名、勤務シフト、個人情報を入力しないでください。公開コードやホーム画面追加自体は保護手段ではありません。
通知配信・サーバー側の定期実行・データベース・権限制御は未実装です。
