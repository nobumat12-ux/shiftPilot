# ShiftPilot v0.5.4 — PWA試作版

GitHub Pagesのリポジトリ直下に `index.html` / `manifest.webmanifest` / `service-worker.js` と `icons/` フォルダを**まとめて**アップロードしてください。従来のHTML単体アップロードではPWA機能が動作しません。

主な変更：PWAホーム画面起動・アイコン・基本オフライン、タスクのワンタップ完了、期限超過表示、他人の進捗の閲覧専用化、希望休への年次有給／半日有給の追加、列並び替えのプレビュー。

**プッシュ通知は未実装です。** iPhoneでアプリを閉じた状態でも通知を送るには、ログイン認証・オンラインデータベース・Push購読情報を保存するサーバー・プッシュ配信処理が必要です。現段階のデータはブラウザ内のみです。実在の個人情報・本物のパスワードは入力しないでください。

既存の `localStorage` キーを維持していますが、試作版の更新前には重要なデータを避け、動作確認用ダミーデータを使用してください。


## v0.5.4 更新
- タスクを作成後に編集・削除（管理者）
- 業務一覧の追加・名称変更・削除、スタッフごとの習熟度0〜3
- 権限・役職・雇用区分を分離、重複するリーダーチェックを廃止
- 週契約の未選択曜日を非表示、基本時間19:00〜23:30を選択曜日に一括入力
- スタッフ本人が契約・技能を閲覧、管理者のみ編集
- 時刻・日付入力欄を画面幅に収めるCSS調整

※データはブラウザのlocalStorageに保存されます。開発用のデモデータ以外の個人情報は登録しないでください。
